What to watch

            
    
              
  • In the memory graph `a` and `b` point at one box: assignment never copies.
  • `a.copy()` copies the outer list only — `c[0]` is still the object `a[0]` pointed at, so the append shows up in `c` too.
  • `copy.deepcopy` is the only line that walks inside and builds fresh inner lists.
  • That is why `d` is unaffected by `a[0].append(99)` and `c` is not.
