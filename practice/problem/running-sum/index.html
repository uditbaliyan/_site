Running Sum of 1d Array Easy running_sum(nums: list[int]) -> list[int]

Return the running sum of nums, where result[i] is the sum of the first i + 1 elements. Order matters.

Example 1
Inputnums = [1,2,3,4]
Output[1,3,6,10]
Each element adds the previous total.
Constraints
1 <= nums.length <= 1000
NUDGE

You never need to look at the whole list again — only at the total so far.

APPROACH

Carry a running total in a variable and append it after each step.

Accumulate OPTIMAL

Keep a total and append it after adding each element.

time O(n) space O(n)
def running_sum(nums: list[int]) -> list[int]: total = 0 out = [] for value in nums: total += value out.append(total) return out
