Loops and accumulators

Carry a value through the loop

Most list problems are one loop plus one variable you keep updating — the accumulator. Summing a list, building a string, counting matches: same shape every time.

Warning: Watch the indentation

The accumulator update must sit inside the loop. If it is outside, only the last value counts — the most common first bug in this lesson's exercise.
